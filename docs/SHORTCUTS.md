# Keyboard shortcuts

On a Mac, use **⌘** where this says **Ctrl**.

## Anywhere in the app

| Keys | What they do |
| --- | --- |
| `Ctrl+K`, or `/` | Search everything: records, sessions, notes, and this help |
| `?` | Help for the screen you are on |
| `Alt+D` | The GM screen |
| `[`, or `Ctrl+\` | Fold the menu down to its icons, or open it again |
| `]` | Open or close the inspector (records you peeked at, pinned stat blocks) |
| `Esc` | Close a hover card, the inspector or a dialog |
| Middle-click a link to a record | Peek at it in the inspector without leaving the page |

`/`, `?`, `[` and `]` do nothing while you are typing in a box, so they can be typed as usual.

## With the keyboard alone

| Keys | What they do |
| --- | --- |
| `Tab`, `Shift+Tab` | To the next thing you can use, or the one before. What has the focus is ringed in gold |
| The first `Tab` on a screen, then `Enter` | **Skip to the page**: past the bars and the menu, straight to the screen's own content |
| `Enter` or `Space` | Press what has the focus |
| `Esc` | Close the dialog or panel you are in; the focus goes back to where it was |

In a dialog, `Tab` goes round the dialog and not out to the page behind it.

## While writing

| Keys | What they do |
| --- | --- |
| `@` | Link a record: start typing its name, `Enter` or `Tab` picks, `Esc` leaves the `@` as typed |
| `Ctrl+B`, `Ctrl+I` | Bold, italic |
| `Ctrl+Alt+2` | A heading |
| `Ctrl+Shift+8` | A list |
| `Ctrl+Shift+9` | A quote |
| `Ctrl+K` | A link |

Everything you write saves by itself a moment after you stop typing.

## During a session

| Keys | What they do |
| --- | --- |
| `Ctrl+Enter` | Add what you typed to the session's log |
