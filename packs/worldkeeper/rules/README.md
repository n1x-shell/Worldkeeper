# The Worldkeeper setting pack

A built-in, removable rules pack with the Worldkeeper setting's own creatures and items, for any campaign: the setting's creatures and hazards (from `packs/worldkeeper/statblocks/statblocks.json`), the Kaelmar items (`packs/worldkeeper/treasure/catalogue.json`) and the Aetheris items (`items-aetheris.json`). It's off until a GM turns it on in **Settings → Rules packs**.

When the **Thinning** mechanic is switched off (Settings → Modules), the entries that use Thinning, true names or Shardscarred use the standard-rules versions in `standard.json`.
