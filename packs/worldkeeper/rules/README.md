# The Oros worldbook's rules

A built-in, removable rules pack with Oros's own creatures, items and species, for any campaign: 40 species for its peoples that play as a book species (`species/`, in the rules-pack Markdown format, v0.9.0); the setting's creatures and hazards (from `packs/worldkeeper/statblocks/statblocks.json`), the Kaelmar items (`packs/worldkeeper/treasure/catalogue.json`) and the Aetheris items (`items-aetheris.json`). It's off until a GM turns it on in **Settings → Rules packs**.

When the **Thinning** mechanic is switched off (Settings → Modules), the entries that use Thinning, true names or Shardscarred use the standard-rules versions in `standard.json`.
