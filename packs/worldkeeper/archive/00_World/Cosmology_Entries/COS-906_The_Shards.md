## Established lore

The Ethereal Crystal broke into twelve shards.

| Shard | Entry |
| --- | --- |
| Dominion | SHD-001 |
| Infinity | SHD-002 |
| Ruin | SHD-003 |
| Sacrifice | SHD-004 |
| Eternity | SHD-005 |
| Illusions | SHD-006 |
| Renewal | SHD-007 |
| Balance | SHD-008 |
| Shadows | SHD-009 |
| Chaos | SHD-010 |
| Knowledge | SHD-011 |
| The twelfth: lost, and nobody remembers what it governed | SHD-012 |

A thirteenth shard exists that should not: the Forgotten One's crystal, SHD-013.

Every shard gives great power and takes something specific in return. Since the Cycle broke, the shards can no longer rewrite existence unless someone relinks them to the Loom [COS-905]. They are still the most powerful objects in the world. (A: Cosmology and history)

The books' five Primary Shards and the Orb are removed. (World Canon Rules [WLD-902])
