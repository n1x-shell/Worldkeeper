# Amsel Lore preflight checklist: v8

## Before making a page

- [ ] Find the entry ID in `Canonical_Entry_Locator_v8.md`.
- [ ] Confirm that its path is not `Worked_Examples/` or `References/`.
- [ ] Check whether the ID lives inside `World Cosmology` or `World Geography` rather than a standalone page.
- [ ] Choose the type and fields from the foundation templates.
- [ ] Paste the complete content; preserve CANON / SECRET / RUMOR / UNDEFINED labels.
- [ ] Link the parent page and related entry IDs; do not create a second page for the same object.
- [ ] Put GM secrets only in GM-controlled visibility locations.
- [ ] Never guess map coordinates or creature mechanics.

## Known exceptions

- [ ] Do not enter the four worked-example ID duplicates.
- [ ] Resolve the Shadowed Sanctum (`LOC-015` / `LOC-505`) alias before linking.
- [ ] Keep Kaelholm `FAC-301` (political power) distinct from `SET-302` (settlement) for now.
- [ ] Keep Root Core and memory-house cross-category pairs clearly linked.
- [ ] Mark referenced but not-yet-built deity, timeline and faction pages as pending, not complete.

## After each group

- [ ] Verify every created page has its stable ID, Name, Category, Parent, Continent/realm, Status, Source and Tags.
- [ ] Check redirects and references manually in the actual Amsel installation.
- [ ] Record any approved structural decisions in `World_Change_Log.md`.
