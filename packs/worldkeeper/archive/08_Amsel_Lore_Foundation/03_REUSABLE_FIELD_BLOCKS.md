# Suggested Reusable Field Blocks (Optional)

These are **field groups to emulate**, not verified Amsel Rune schemas. Use plain text if your version of Lore does not support reusable blocks.

## Canon block
`Canon status`, `Source`, `Last reviewed`, `Approval note`.

## Visibility block
`Player visibility`, `Secret summary`, `Player-safe counterpart`.

## Game mechanics block
`Mechanics label` (OFFICIAL / HOMEBREW / OUTSIDE 2024 CORE), `Rules source`, `Exact page verified?`, `Check required`.

## Magic cost block
`Activation`, `Cost`, `Consequence`, `Current holder`, `Unverified mechanics`.

## Dating block
`After Bloom (AB)`, `Unbound year` and `Relative era`.

**Cross-calendar note:** the source documents establish 300 AB = Year 31 Unbound and use `Unbound = AB - 269`. Do not assign an exact Unbound date to pre-Unbound events using a conversion that could create misleading year numbering. Mark those events by era when appropriate.

## Relationship block
`Related entry Name [ID]`, `Relationship`, `Source`, `Player-visible?`.

For a first implementation, use only Canon and Visibility blocks; add more if repetitive manual entry becomes burdensome.
