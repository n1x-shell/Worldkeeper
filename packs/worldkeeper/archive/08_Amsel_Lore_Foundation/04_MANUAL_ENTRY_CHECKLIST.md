# Manual Entry Checklist: Amsel Lore

## Before setup

- [ ] Back up the two original setting bibles and the current continuation package.
- [ ] Open Amsel Lore and confirm the actual page hierarchy, entry fields, link behavior, tags, templates, and permissions available in this version.
- [ ] If a feature is absent, use ordinary text lines; do not assume Markdown or `.LoreKit` world-content import.
- [ ] Establish a GM-only section for secrets; do not share mixed secret/public pages.

## Foundation (recommended order)

- [ ] Create **The World [WLD-901]** and place the existing overview beneath it.
- [ ] Create **Aetheris [CON-001]**, **Kaelmar [CON-301]**, **Ethereal Realm [CON-501]**.
- [ ] Create world reference pages: canon rules, cosmology, timeline, geography, continental links, mysteries, possible futures.
- [ ] Create shared systems: calendar, money, languages, travel. Attach the existing files.
- [ ] Add the main reference directories for People and Organizations, Shards and Relics, Thirteen Vaults, and Gods.
- [ ] Check existing IDs before making new entries; never silently reassign one.

## Prove the design on five pages

- [ ] Copy Aetheris worked example into a Continent layout.
- [ ] Copy Kaelmar worked example into a Continent layout.
- [ ] Copy Ashvale worked example into a Settlement layout.
- [ ] Copy Seed Vault worked example into a Vault layout.
- [ ] Copy the Rift worked example into a Landmark layout.
- [ ] Confirm metadata fields and text layout remain readable in Lore.
- [ ] Turn `Name [ID]` references into clickable links if supported.
- [ ] Confirm GM-only material is not visible in player-facing views.

## Before bulk entry

- [ ] Mark which templates are truly supported as native templates and which are pasteable text structures.
- [ ] Confirm page nesting, tagging, link creation, and visibility with actual app behavior.
- [ ] Add a changelog entry when you change a field or template.
- [ ] Use `05_ENTRY_QUALITY_CHECK.md` on every later content batch.

## Initial milestone

Complete foundation pages and five examples before entering the 96 Aetheris NPCs, Kaelmar's vaults, and other detailed entity records. This minimizes rework.
