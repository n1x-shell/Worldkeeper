# Aetheris Locations Peoples and Rules v5

## Added this pass
- 12 individual location references, plus a legendary-site index. The Loom has one authoritative record at [ETH-505], rather than an extra duplicate.
- 7 culture and species reference pages; 10 playable calling pages; 2 lineage records grouped in one page; non-playable Hidden One callings grouped in one page.
- 10 source-derived rules reference documents, plus a removed-mechanics safeguard and culture, Type, title and faith indexes.

## Manual entry order
1. Read Legendary Sites Index, then create only those site pages that matter in play.
2. Create the seven peoples and ten callings using your reusable Amsel templates.
3. Keep source-provided D&D adaptations separate from setting lore. Check any mechanics before they reach the table.
4. Add the grouped Types, backgrounds, and regional-effect indexes; copy over item-specific details from v4 when needed.

## Authority and gaps
All established statements come from the approved Aetheris bible. Unspecified coordinates, mechanics and detailed histories remain undefined. No new lore facts or homebrew mechanics have been invented. The earlier docs and records are preserved. If a proposed external reference conflicts with the approved bible, the approved bible controls.
