# True-Name Mirror

## Rarity and attunement (existing homebrew)
Very rare

## Existing effect [HOMEBREW; not independently rules verified]
A creature that sees itself in the mirror learns its true name, and has Advantage on saves against Thinning while it remembers. You can learn the true name of any creature it reflects (Wisdom save DC 17 to resist).
