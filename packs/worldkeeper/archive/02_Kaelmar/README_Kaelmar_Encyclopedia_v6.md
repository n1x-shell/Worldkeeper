# Kaelmar Encyclopedia v6: Read Me

This package adds 71 source-grounded Kaelmar Markdown files to the existing unified world, retaining every earlier file.

## What's organized
- Six regional pages plus a geography directory
- Ashvale and Kaelholm with the nine nearby settlements folded into an Ashvale reference
- Ten significant site entries, including the Rite Circle, under-roads, memory-house and Sentinel Hold
- Thirteen sealed vault pages, each containing the approved key and relevant source details, plus a key index
- Eleven faction/power records and thirteen individual Kaelmar NPC records. The Forgotten One is linked to the existing NPC-901 page rather than duplicated
- Four magic references, four rules references, and the people/creature directories
- Original chronology and multiple cross-reference indexes

## Editorial boundaries
Every setting fact comes from `Kaelmar_Setting_Bible.md`. Existing New content was approved by the world owner and is treated as CANON. All thirteen vaults are sealed at 300 AB. Guardian and Root Core sleep. The events from the novel in 927 AB remain one possible future.

Homebrew is marked, official mechanical baselines are not revalidated, and unknown map details and NPC attributes remain UNDEFINED. Files are designed for manual entry into Amsel Lore, not a proprietary import format. World and Aetheris documents from v5 are preserved.

## Suggested Amsel entry order
1. Kaelmar [CON-301] (already present) and six regions
2. Ashvale [SET-301], Rite Circle [LOC-301], the nine settlement directory, and Kaelholm [SET-302]
3. The thirteen vaults and their key catalog
4. The active factions, NPCs, and core magic systems
5. Remaining sites, rules and creature references

Separate GM-only pages or protect secrets: the files mark DM-sensitive material, but a Markdown heading does not enforce visibility in Amsel Lore.

## Worked examples and single authoritative records

The `08_Amsel_Lore_Foundation/Worked_Examples` folder contains teaching copies of Kaelmar [CON-301], Ashvale [SET-301] and the Seed Vault [VLT-301]. Those are **not additional entities**. For ongoing Lore entries, use the continent overview in `02_Kaelmar`, Ashvale in `02_Kaelmar/Ashvale_and_the_Rift` and the Seed Vault in `02_Kaelmar/Vaults`. These canonical pages supersede the shorter worked examples.
