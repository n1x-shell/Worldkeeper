# The First Rasp

## Description
A bone-handled scraping knife, Kaelholm's first, used to burn the first name from the first roll.

## Lore power
Scrapes a name from any record, roll or memory-crystal, so completely that the written name is gone from every copy.

## Lore cost
Each use, one person who knows the wielder forgets their name.

## Where it is (GM)
Kept in the Rasp in Kaelholm, under glass. The one under glass is a copy.

## Mechanics
No 2024 rules are assigned. Build them from the power and the cost when the party finds it.
